FAQ

Questions before you explore.

Short answers to the things you may want to know before opening the platform.

What is GeoStatix?

GeoStatix is an interactive platform for statistical and geostatistical analysis of geological datasets.

Do I need programming knowledge?

No. The platform provides an interactive interface so you can perform the main workflows without writing analysis code.

Can I use my own geological data?

Yes. You can upload CSV or XLSX data, or start with one of the built-in demonstration datasets.

Which spatial methods are available?

GeoStatix currently includes spatial mapping, variograms, IDW interpolation, Ordinary Kriging, uncertainty analysis and cross-validation.

What should I use the demo datasets for?

They let you explore the workflow immediately, understand the outputs and learn how the platform behaves before uploading your own data.

Is GeoStatix still being developed?

Yes. The platform is designed as an evolving geoscience analytics project, with room for additional methods, datasets and user feedback.
